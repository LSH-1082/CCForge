# 주제별 규칙 예시

`rules/<주제>/` 하나가 한 영역의 규칙이다. 이 디렉터리는 형식 예시이며, 디렉터리 이름이 `_`로 시작하면 CCForge가 적용하지 않는다. 복사해서 `rules/python/`처럼 이름을 바꿔 쓴다.

## 적용 대상

- `**/*.py`
- `scripts/**`

바뀌는 파일 중 하나라도 위 패턴에 해당하는 step에 이 디렉터리의 모든 `*.md`가 적용된다. 이 절이 없으면 모든 step에 적용한다.

## 규칙

- [implementation·medium] 함수 시그니처에 타입 힌트를 단다.
- [implementation·low] 모듈 최상단에서 부수 효과가 있는 코드를 실행하지 않는다.
